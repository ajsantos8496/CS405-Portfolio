# CS405-Portfolio

This repository contains my work from CS405: Secure Coding, including the Project One Security Policy, Project Two Presentation, coding activity ZIP files, and portfolio journal reflection. The coding activities cover numeric overflow and underflow, SQL injection, buffer overflow, exception handling, unit testing with Google Test, XOR encryption, and static code analysis. Together, these assignments show how I used secure coding practices to address vulnerabilities and tested the code to evaluate those changes.
